Levenshtein (Edit) Distance

The minimum number of single-character insertions, deletions, or substitutions needed to turn one word into another. Used for spell-checkers, fuzzy matching, and DNA sequence comparison.
The recurrence
D(i,j) = max(i,j)   if min(i,j) = 0
D(i,j) = min
D(i−1, j) + 1 (delete)
D(i, j−1) + 1 (insert)
D(i−1, j−1) + cost (match / substitute)
D(i,j) is the edit distance between the first i characters of the source and the first j characters of the target — exactly the value in cell (i,j) of the grid on the right. cost = 0 if the characters match, 1 otherwise.

Type-Token Ratio (TTR)

A quick measure of lexical diversity. A token is any word occurrence; a type is a distinct word. A high ratio means little repetition, a low ratio means the text leans on the same words often.
The formula
TTR = |V|N
|V| is the number of unique word types, N is the total token count. TTR ranges 0–1 — closer to 1 means almost every word is different; closer to 0 means heavy repetition.

Gradient descent nudges the slope m and intercept b downhill on the loss surface until the fitted line stops improving. The right panel is that loss surface — teal is low loss, red is high — with the descent path traced across it.

k-Means Clustering

k-Means alternates two steps: assign every point to its nearest centroid (×), then update each centroid to the mean of its assigned points. Step through it manually or run it to convergence.
Objective and the two steps
J = Σki=1Σx∈Ci‖x−μi‖2
Assign: c(x) = argmini ‖x−μi‖2
Update: μi = 1|Ci|Σx∈Ci x
J is the inertia charted on the right — total squared distance from every point to its own centroid. Each full assign/update cycle can only decrease or hold J, which is why it's guaranteed to converge.

Decision Boundary (Logistic Regression)

Logistic regression learns a straight boundary that separates the two classes by minimizing cross-entropy loss with gradient descent. Misclassified points are ringed; the shaded background is the model's predicted class at every location.
Model and loss
σ(z) = 11+e−z     p̂ = σ(w1x1+w2x2+b)
L = −1nΣni=1[yi log p̂i + (1−yi) log(1−p̂i)]
The boundary drawn is where p̂ = 0.5, i.e. w1x1+w2x2+b = 0 — a straight line because the model is linear in x1,x2 even though σ itself is curved.

Confusion Matrix, Precision, Recall, F1

Each dot is an example scored by a classifier (0–1) with a true class. Sliding the decision threshold changes which dots count as "predicted positive" — watch precision, recall, and F1 trade off as the threshold moves.
The four metrics
Precision = TPTP+FP     Recall = TPTP+FN
F1 = 2·P·RP+R     Accuracy = TP+TNTP+TN+FP+FN
Raising the threshold shrinks the "predicted positive" region — FP tends to fall (precision rises) but FN tends to rise (recall falls). F1 is the harmonic mean of precision and recall, so it drops sharply if either one is low.

Subnetting

A CIDR prefix (e.g. /24) says how many of the 32 bits are "network" bits (teal) versus "host" bits (red). Drag the slider to see the subnet mask, network address, broadcast address, and usable host range recompute live.
Key formulas
Network = IP AND Mask     Broadcast = Network OR (NOT Mask)
Usable hosts = 2(32−prefix) − 2
AND / OR / NOT are bitwise operations on the 32-bit address. NOT Mask (the wildcard mask) flips every bit of the mask. The −2 excludes the network and broadcast addresses themselves — except at /31 and /32, which have their own special-case rules (used for point-to-point links and single hosts).

Bit-Banding

The Cortex-M4 maps every individual bit in a 1MB bit-band region to its own 32-bit word in a separate 32MB alias region — write 1 or 0 to that alias word and only that one bit flips, atomically, no read-modify-write needed.

The formula
alias_addr = alias_base + (byte_offset × 32) + (bit_number × 4)
